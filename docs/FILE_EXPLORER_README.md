## Usage

### Getting Started

1. Start the development server: `yarn dev:frontend`
2. Open your browser to the local development URL
3. Click "Create Root Directory" to initialize the file system

### Basic Operations

1. **Select Items**: Click on any file or directory to select it
2. **Expand/Collapse**: Click the arrow button next to directories to expand/collapse them
3. **Create New Items**:
   - Select a directory
   - Click "Create New Item"
   - Choose file or directory type
   - Enter a name and click "Create"
4. **Delete Items**: Select an item and click "Delete Selected"

### Advanced Features

- **Expand All**: Shows all directories and their contents
- **Collapse All**: Hides all directory contents
- **Generate Example Data**: Creates a complex file system with 10K+ files for performance testing

- **Efficient Updates**: Minimal state changes and re-renders
- **Lazy Loading**: Tree items loaded on demand

### Error Handling

- **Validation**: Comprehensive input validation
- **Safety Checks**: Prevents invalid operations (e.g., deleting root)
- **User Feedback**: Clear error messages for all failure cases
- **Recovery**: Graceful handling of edge cases

## File System Rules

### Naming Conventions

- Names cannot be empty
- Names cannot contain path separators (/, \\)
- Names must be unique within the same directory

### Operations

- Root directory cannot be deleted
- Only directories can contain other items
- Deleting a directory removes all its contents recursively
- All operations maintain referential integrity

### Performance Considerations

- File system is stored entirely in memory
- Virtualization handles rendering of large datasets
- Efficient algorithms for tree traversal and updates
- Optimized data structures for fast lookups
