# File Explorer Application Guide

This document provides comprehensive information about the In-Browser File Explorer application features, usage, and technical implementation.

> **🔧 For development setup and project configuration, see [README.md](../README.md)**

## Overview

The In-Browser File Explorer is a fully functional, frontend-only file explorer built with React and TypeScript. It provides a virtualized tree view that can efficiently handle large file systems with thousands of files, featuring modern UI design and comprehensive error handling.

> **Note**: A large portion of the initial code (including this documentation) was generated by Cursor, with reviews, refactoring and improvements (including bugfixing) being done iteratively.

## Features

### Core Functionality

- **File System Management**: Complete in-memory file system supporting files and directories
- **Tree View**: Hierarchical display of files and directories with expand/collapse functionality
- **Selection**: Click to select files or directories for operations
- **Create Operations**: Create new files or directories with custom names
- **Delete Operations**: Remove selected files or directories (with safety checks)
- **Drag and Drop**: Move files and directories between directories by dragging
- **Performance**: Virtualized rendering for handling large datasets (10K+ files)

### User Interface

- **Modern Design**: Clean, intuitive interface built with Tailwind CSS
- **Responsive Design**: Mobile-first approach with responsive breakpoints
- **Interactive Elements**: Hover effects, transitions, and visual feedback
- **Error Handling**: Comprehensive error messages with styled alerts
- **Statistics**: Real-time display of file system statistics
- **Accessibility**: Basic accessibility with semantic HTML and ARIA attributes

### Performance Features

- **Virtualization**: Only renders visible items in the tree view
- **Efficient Updates**: Minimal re-renders using React optimization techniques
- **Memory Management**: Efficient data structures for large file systems
- **Smooth Scrolling**: Optimized scrolling performance for large lists

## Usage

### Getting Started

1. Start the development server: `yarn dev`
2. Open your browser to http://localhost:3000
3. Click "Create Root Directory" to initialize the file system

### Basic Operations

1. **Select Items**: Click on any file or directory to select it
2. **Expand/Collapse**: Click the arrow button next to directories to expand/collapse them
3. **Create New Items**:
   - Select a directory
   - Click "➕ Create New Item"
   - Choose file or directory type
   - Enter a name and click "Create"
4. **Delete Items**: Select an item and click "🗑️ Delete Selected"
5. **Move Items**: Drag and drop files/directories onto target directories
6. **Reset System**: Click "🔄 Reset File System" to clear all data

### Advanced Features

- **Expand All**: Shows all directories and their contents
- **Collapse All**: Hides all directory contents
- **Generate Example Data**: Creates a complex file system with 10K+ files for performance testing
- **Reset File System**: Clears all data and creates a new root directory
- **Drag and Drop**: Move items between directories by dragging them

## File System Rules

### Naming Conventions

- Names cannot be empty
- Names cannot contain path separators (/, \\)
- Names must be unique within the same directory

### Operations

- Root directory cannot be deleted
- Only directories can contain other items
- Deleting a directory removes all its contents recursively
- All operations maintain referential integrity

### Performance Considerations

- File system is stored entirely in memory
- Virtualization handles rendering of large datasets
- Efficient algorithms for tree traversal and updates
- Optimized data structures for fast lookups

## Technical Implementation

### Architecture

- **FileSystemContext**: Core React context managing file system state and operations (455 lines - could benefit from refactoring)
- **TreeContext**: Manages tree expansion/collapse state and navigation
- **VirtualizedTree**: Performance-optimized tree component with drag and drop support
- **FileExplorer**: Main UI container orchestrating all functionality
- **Custom Hooks**: Specialized hooks for statistics, sample data generation, and virtualization
- **DnD Kit**: Drag and drop functionality using @dnd-kit/core
- **TypeScript**: Full type safety throughout the application
- **Tailwind CSS**: Utility-first CSS framework with Vite plugin integration

### Data Structures

- **FileSystemNode**: Represents individual files and directories with metadata
- **FileSystemState**: Manages the complete file system state using Map-based storage
- **TreeNode**: Optimized structure for tree rendering with visibility and expansion state
- **CreateNodeRequest**: Interface for creating new nodes
- **FileSystemError**: Typed error handling with specific error codes

### Performance Optimizations

- **Virtual Scrolling**: Only renders visible tree items using custom virtualization
- **Context-based State Management**: Efficient state updates using React Context API
- **Memoization**: React.useMemo and useCallback for expensive operations
- **Map-based Storage**: Fast O(1) lookups using JavaScript Map for node storage
- **Efficient Tree Traversal**: Optimized algorithms for tree operations and updates
- **Lazy State Updates**: Minimal re-renders through careful state management

### Error Handling

- **Typed Error System**: FileSystemError with specific error codes (NODE_NOT_FOUND, INVALID_NAME, etc.)
- **Validation**: Comprehensive input validation for node creation and operations
- **Safety Checks**: Prevents invalid operations (e.g., deleting root directory)
- **User Feedback**: Clear error messages displayed through ErrorDisplay component
- **Error Recovery**: Graceful handling of edge cases with error clearing functionality
- **Error Boundaries**: React ErrorBoundary components for catching and displaying errors
